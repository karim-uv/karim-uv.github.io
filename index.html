About

I started my degree in Debrecen in 2023 and moved to Budapest in 2026, partly for the work and partly because a bigger city gives you more to aim at.

Most of what I have built is server-side: authentication, data models, the parts of an application that have to be right before anything else can be. Recently I have been working on the other end of that — tooling that enforces a standard automatically, so a team does not have to remember it. That interest came out of a hackathon and has not gone away.

Alongside university I run my own registered business in Budapest, which has taught me more about deadlines, invoicing and self-management than any course has.

EAA Gatekeeper

A GitHub Action that checks a pull request against EU accessibility law. It scans only the lines that changed and comments inline on each problem with the rule it breaks and a suggested fix, then blocks the merge until the branch is clean.
